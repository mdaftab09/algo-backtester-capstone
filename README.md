# 📈 Algorithmic Trading Backtester & Market Anomaly Predictor

> A modular, Object-Oriented quantitative trading pipeline built in Python. This system ingests historical market data, identifies pricing anomalies using **Machine Learning (Isolation Forests)** and statistical models, and backtests custom trading strategies to evaluate **risk-adjusted returns**.

## 📖 About the Project

This project provides a complete quantitative trading research pipeline that combines **statistical analysis**, **machine learning**, and **backtesting** into a modular architecture.

The system automatically:

- 📊 Downloads historical OHLCV market data
- 🤖 Detects unusual market behavior using Isolation Forests
- 📈 Executes multiple trading strategies
- 💰 Simulates portfolio performance with transaction costs
- 📉 Evaluates strategy performance using quantitative risk metrics

## 🏗️ Project Architecture

The project follows a modular, Object-Oriented design where each component has a single responsibility.

| Module | Responsibility |
|---------|---------------|
| `data_loader.py` | Downloads and cleans historical OHLCV data, handles missing values, and generates rolling statistical features. |
| `anomaly_detector.py` | Uses Scikit-learn's `IsolationForest` to identify unusual price movements and volatility spikes. |
| `strategies.py` | Implements trading strategies including Dual Moving Average Crossover and an ML-driven Anomaly Fader. |
| `backtester.py` | Simulates trade execution, applies transaction costs (0.1%), and tracks portfolio equity. |
| `metrics.py` | Computes Sharpe Ratio, Maximum Drawdown, Win Rate, and other performance metrics. |
| `main.py` | Coordinates the complete trading pipeline. |

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/mdaftab09/algo-backtester.git
cd algo-backtester
```

---

### 2. Create a virtual environment (Optional but Recommended)

**Windows (PowerShell)**

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**macOS / Linux**

```bash
python3 -m venv venv
source venv/bin/activate
```

---

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

---

### 4. Run the pipeline

```bash
python main.py
```
